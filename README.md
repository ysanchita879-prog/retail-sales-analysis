# Retail Sales Data Visualisation Project

**Student:** Sanchita Yadav  
**Course:** BBA-IBM

## Project overview
This beginner-friendly project uses a sample retail sales dataset to demonstrate four types of data visualisation. The dataset is fictional and created for academic practice; it does not represent a real company.

## Objectives
- Organise retail sales data in CSV format.
- Visualise sales trends and compare products, categories and regions.
- Present findings in clear charts.

## Tools
- Python
- Pandas
- Matplotlib
- GitHub

## Visualisations
1. Line chart: monthly sales revenue.
2. Horizontal bar chart: revenue by product.
3. Pie chart: revenue share by category.
4. Bar chart: revenue by region.

## How to run
Install the required libraries:
```bash
pip install pandas matplotlib
```
Keep `sales_data.csv` and `visualize_sales.py` in the same folder, then run:
```bash
python visualize_sales.py
```
The script creates four PNG chart files in the same folder.

## Conclusion
Visualisation makes it easier to identify monthly sales patterns and compare the contribution of different products, categories and regions. This project demonstrates how data can be converted into understandable visual information.
